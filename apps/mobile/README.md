# @dispatch/mobile

React Native (Expo) app with two modes from one codebase:

- **Customer** — create a delivery, pay, track the rider, share tracking, rate, report an issue.
- **Rider** — apply and verify, go online, receive and accept offers, update status, proof of delivery, earnings.

Not scaffolded yet. Screens are built alongside each MVP step in [`docs/system-design/12-roadmap.md`](../../docs/system-design/12-roadmap.md).
