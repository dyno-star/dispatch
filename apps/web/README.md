# @dispatch/web

Next.js app for two surfaces that run in a browser:

- **Admin panel** — rider verification, orders, payments, disputes (staff login).
- **Public tracking page** — `/t/:token`, read-only live tracking for recipients. No account, no app.

Not scaffolded yet. Built in MVP step 4 (tracking page) and step 6 (admin panel). See [`docs/system-design/12-roadmap.md`](../../docs/system-design/12-roadmap.md).
